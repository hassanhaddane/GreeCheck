# GreeCheck 3.0 · Audit fonctionnel

Référence inspectée : commit 95c312f sur develop, sous Node 22.23.1 et npm 10.9.8. L'audit croise le code des routes et composants, les stores et services, le domaine pur, les trois catalogues et les suites Node et Playwright. Le README annonce encore Next.js 14. PROJECT_CONTEXT.txt et les inventaires V2 décrivent des étapes précédentes, notamment une liste absente et un Battle autonome. Le code au commit de référence utilise Next.js 16.2, possède une liste et dirige déjà Battle vers Compare. Pour le score, les tests GS-2 et les moteurs priment sur l'ancienne pondération V1.

## Constats techniques

| TypeScript et erreurs | Mode strict, contrats typés pour la résolution d'un produit, le niveau de confiance et les erreurs réseau. | Non évaluable | La fiche affiche le statut et sa cause. Le moteur fournit encore 50/C en compatibilité legacy. La carte de résultat, le scan rapide et les snapshots bibliothèque consomment ces champs. L'historique les transmet aux statistiques. P0 pour fermer ces fuites avant toute évolution du score. |
| Duplication | La recherche dispose déjà d'une carte partagée. Les lignes historique et favoris ont une présentation voisine mais des actions, filtres et métadonnées distincts. Les conserver pendant le changement de navigation puis extraire seulement la présentation commune si elle converge. |
| Cache et performance | Le proxy OFF revalide les requêtes publiques. La fiche a une lecture serveur pour SEO/JSON-LD et une lecture client pour le rendu/cache IndexedDB, avec risque de données divergentes. Le repository déduplique les lectures, sert le cache frais pendant 24 h et peut servir un produit périmé signalé. Le service worker garde le shell et des pages déjà visitées, avec un fallback. | Confidentialité et garde-fous | Les préférences ne sont pas jointes aux appels produit. Les recherches circulent vers le proxy et le moteur OFF, les coordonnées vers le proxy lieux et Overpass. ## Couverture et référence

- Typage application et domaine, lint application et domaine, build de production et 239 tests Node réussis avant modification.
- Playwright Chromium Windows avant modification : 21 parcours sur 22 réussis hors visuels. Le test SEO Nutella échoue avant et après la réorganisation. Le lookup réel renvoie usable_incomplete et missingNutriScore. La fiche affiche donc le titre générique et applique sa règle d'indexation pour les produits incomplets. Le scénario du produit déjà mis en cache est passé.
- Le dépôt contient des références visuelles Linux uniquement. Une exécution Windows de référence a reproduit l'absence de capture attendue pour la plateforme. Ce cas est distinct du changement intentionnel de navigation.
- Couverts : moteurs de score, impact, alternatives, comparaison, panier, Coach et semaine, parseur OCR et scanner, cache et migrations Dexie, états principaux, recherche, accessibilité automatisée, PWA et RTL. Les tests applicatifs n'interceptent pas tous les fetchs serveur, et l'axe n'est exécuté que sur quelques pages.
- À couvrir : SEO avec une source locale déterministe, caméras et installation sur appareils, montée de version du service worker, faible stockage ou IndexedDB bloqué, concurrence entre onglets, OCR réel, cache et provenance lors d'une mise à jour d'un produit, résultats AR sur un catalogue pertinent.
